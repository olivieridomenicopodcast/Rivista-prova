# Interferenza

Numero 1 di un mensile immaginario, sfogliabile nel browser. Nove temi (giochi da tavolo, videogiochi, musica, composizione musicale, podcasting, radioamatorismo, vibe coding, geografia, libri), ognuno letto da una chiave di lettura non ovvia e con un piccolo esperimento interattivo.

Un solo file, nessuna build: apri `index.html` in un browser.

- Desktop: doppia pagina con volta 3D. Telefono: pagina singola.
- Navigazione: frecce della tastiera, swipe, clic sul margine, chip colorati per saltare alle sezioni.
- Ogni pagina ha un indirizzo, per esempio `index.html#pagina-13`.
- Il suono (Morse, poliritmo) parte solo dopo un clic.
